# 开源发布清单

## 发布前核对

- [ ] 确认源码、商标、截图、文档和第三方素材的发布权利
- [ ] 检查源码、Git 历史、附件和归档中不存在密钥、个人数据、生产地址或业务资料
- [ ] 复核 Mulan PSL v2 与每项直接及传递依赖的许可证要求
- [ ] 在干净环境按锁文件安装后端与前端依赖
- [ ] 执行后端测试、前端源码检查和生产构建
- [ ] 校验 Docker Compose 配置；需要部署时再执行目标环境验收
- [ ] 检查 README 链接、启动步骤、默认配置和可选集成说明
- [ ] 生成发行归档及成员清单，并对归档再做一次内容审查
- [ ] 为正式发行确定版本号、变更记录和下载地址

## 证据边界

源码扫描、静态检查、模拟模式、真实数据库、真实模型、浏览器操作和生产运行是不同的证据类型。逐项记录执行环境、命令、结果和未覆盖范围；未执行的项目保持未勾选。
