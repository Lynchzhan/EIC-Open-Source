# 公开演示与限时体验

体验入口使用 EIC 的共享页面组件，并通过单独的体验 API 与业务 API 隔离。实际可用页面、资源和运行限制由部署者配置。

## 模式

| 模式 | 数据与调用 | 交互范围 |
| --- | --- | --- |
| 公开演示 | 虚构资料，不访问业务数据或真实模型 | 可浏览 EIC 页面、查看示例内容和模拟多轮对话 |
| 限时体验 | 管理员明确授权的模型、Agent 与知识库 | 在时间、调用量和资源权限范围内运行真实对话 |

公开模式中的模型、知识库和组织信息必须使用合成数据。模型凭据、真实用户资料、业务文档、正式日志和观测信息不能进入公开演示。

## 资格管理

管理员可配置入口开关、可见页面、允许体验的资源和预算，并创建限时链接或独立账号。资格应具有明确的开始条件、结束时间、用量上限和撤销方式；体验身份不能获得正式用户的 JWT 或绕过业务权限。

真实体验只允许访问被授权的只读业务资源。若启用真实模型，需清晰展示可能产生的外部调用和费用；工具调用、MCP、上传、入库、后台任务、长期记忆等能力应分别授权，默认关闭。

## 数据与安全边界

- 使用独立体验身份和专用 API；不把体验请求回退到正式用户 API。
- 公开演示使用内置虚构内容；不能以自动脱敏代替人工审查。
- 限时体验的会话内容使用独立存储，设置到期清理；删除保证受操作系统、存储介质和备份策略限制。
- 不将体验问题或回复写入浏览器长期存储。接口使用适当的 `no-store` 响应策略。
- 体验内容是否进入正式观测系统必须由部署配置明确控制，并告知体验者。
- 到期取消本地请求不能保证上游模型已停止计算或不再计费。

## 部署者验收

先使用合成数据验证公开页面、匿名访问拒绝、资格过期、撤销、并发请求、数据清理和权限隔离。真实模型路径应单独评估预算与费用，并确认服务提供方的数据保留条款。多实例部署还需验证共享控制存储和跨实例撤销行为。

源码中的演示实现和测试不代表部署者已完成浏览器、安全、真实模型或生产容量验收。
