## 覆盖边界

- 页面主导航 21 项均有截图；消息分类 5 项和可安全打开的主要管理窗口有独立截图。
- 技能与工具页的 `Tool / Skill / MCP` 页签在当前云端界面渲染为空白且不可见，未伪造选中状态。
- 知识库卡片上的检索策略控件会直接写入云端设置，因此只保留当前状态并截图，没有切换策略。
- 体验资格编辑按钮当前不可用（无有效可编辑记录），没有伪造编辑窗口。删除、撤销、执行、保存等确认窗口未确认。
- README 精选图展示实际运行界面；动态数据遮罩后，截图不应被理解为未脱敏的生产数据展示。
- 自动任务画面显示功能未启用、队列暂不可用；页面按钮和计划字段不是任务已成功执行的证明。
- 部分详情、记忆与检索窗口因脱敏较重，仅作为覆盖记录放在完整画廊；首页优先选择标题与控件较清晰的画面，不恢复遮罩内容。
- 截图展示界面与配置入口，不替代模型效果、工具执行、资源隔离、处理成功或部署容量的独立验收。登录入口是否开放由实际部署配置决定。
